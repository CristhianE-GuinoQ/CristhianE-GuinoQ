### 🔐 Sistema de Registro y Control de Visitas RENIEC

Institutional web system for visitor registration, entry and exit control, daily statistics and report generation.

**Main features:**

- Login with DNI and password
- Authentication with JWT
- Administrative dashboard
- Visitor registration
- List of registered visits
- Entry and exit control
- Recent activity panel
- PDF, Excel and print reports
- PostgreSQL database
- Backend with Laravel
- Frontend with Blade, JavaScript and AdminLTE

**Technologies used:**  
Laravel, PHP, PostgreSQL, JavaScript, HTML, CSS, JWT, AdminLTE, jsPDF, ExcelJS
