## 🚀 Actualmente estoy trabajando en

### Sistema de Registro de Visitas RENIEC

Sistema web institucional que permite registrar visitantes, controlar ingresos y salidas, visualizar estadísticas del día y generar reportes en PDF, Excel e impresión.

Funciones principales:

- Login institucional con DNI y contraseña
- Autenticación con JWT
- Dashboard administrativo
- Registro de visitantes
- Listado de visitas
- Control de ingreso y salida
- Actividad reciente
- Reportes en PDF, Excel e impresión
- Base de datos en PostgreSQL
